docker container ls: lista los contenedores

docker container list: El mismo resultado.

docker container ls -n 5: Muestra los últimos contenedores tanto en ejecución como detenidos. -n para mostrar la cantidad con "5".

docker container ls -q: Muestra solo el id de contenedor.

docker container ls –quiet: Devuelve los id de contenedores en modo silencioso.

docker container ls --filter "status=exited": Filtrar por el estado de un contenedor.

Get-ChildItem -Path C:\ -Directory -ErrorAction SilentlyContinue |
  ForEach-Object {
    $sizeBytes = (Get-ChildItem -Path $_.FullName -Recurse -ErrorAction SilentlyContinue |
      Measure-Object -Property Length -Sum).Sum
    [PSCustomObject]@{
      Folder = $_.FullName
      SizeGB = [math]::Round($sizeBytes / 1GB, 2)
    }
  } | Sort-Object SizeGB -Descending | Select-Object -First 50
